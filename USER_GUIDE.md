# User Guide

## Operator
- **Login**: Use your Employee ID and Password.
- **Start Inspection**: Click "Scan QR" or manually paste the `PART;SERIAL;VENDOR` string.
- **Checklist**: Complete each question. Select "OK" or "NOT OK". 
- **Photos**: If a question requires a photo, you must upload a JPG/PNG under 10MB.
- **Submit**: Review your answers on the final screen and click Submit.

## Manager
- **Dashboard**: View high-level metrics of all inspections.
- **Inspection Monitor**: View the live status of all shop-floor inspections.
- **Checklist CRUD**: Navigate to Checklist Manager to Add, Edit, or Soft-Delete questions.
- **Operator Mode**: When viewing an "IN_PROGRESS" inspection, click "Switch to Operator Mode" to assume control and help finish the inspection.

## Admin
- **Dashboard**: View high-level metrics on active Users.
- **User Management**: Create users, reset passwords, change roles, and deactivate terminated employees.
- **Inspection Monitor**: Read-only view of shop floor progress.
- **Audit Log**: Track every critical action (Logins, Inspections, User modifications) across the entire application.
