# Changelog

## v1.0
- **Phase 1 (Project Foundation)**: Initialized FastAPI and React Vite scaffolding.
- **Phase 2 (Database Foundation)**: Designed and executed Oracle 19c Schema, Views, and Triggers.
- **Phase 3 (Authentication)**: Implemented JWT Role-based Access Control (Admin, Manager, Operator).
- **Phase 4 (Operator Module)**: Created the QR parser, Checklist UI, BLOB Photo Upload, and Submit workflow.
- **Phase 5 (Manager Module)**: Developed the Inspection Monitor, Checklist CRUD, and Manager-Operator takeover mode.
- **Phase 6 (Admin Module)**: Developed the User Management Dashboard and immutable Audit Log.
- **Phase 7 (UI/UX Polish)**: Standardized to Cummins Blue theme, implemented Snackbar Context, Table Skeletons, and Empty States.
- **Phase 8 (Security & Performance)**: Implemented global Exception Handlers, 10MB Photo limits, N+1 query fixes, and Lazy Routing.
- **Phase 9 (QA & Production Readiness)**: Final code scrub, dependency locking, and workflow verification.
- **Phase 10 (Deployment & Handover)**: Comprehensive documentation generation and final project release.
