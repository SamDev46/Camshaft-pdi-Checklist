# CamTrace v1.0

CamTrace is a robust, production-ready enterprise application for monitoring camshaft inspections on the production floor.

## Features
- Role-based Access Control (Operator, Manager, Admin)
- QR-code initiated Inspections
- Photographic Validation with size/type constraints
- Live Inspection Monitoring and Audit Logging
- Fully Responsive UI (optimized for tablets)

## Technology Stack
- **Database**: Oracle 19c
- **Backend**: Python 3.10+, FastAPI, SQLAlchemy, oracledb
- **Frontend**: Node.js 18+, React, Vite, MUI

## Folder Structure
```

├── frontend/   # React/Vite Application
```
